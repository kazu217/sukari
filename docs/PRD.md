# Product Requirements Document — PriceLens（仮）

## プロダクトビジョン

「リアル店舗で商品を見た瞬間に、仕入れ判断ができる」

転売・せどり業者が店舗で商品を発見した時、3秒以内に「買い」か「スルー」かを判断できるアプリ。

---

## ユーザーペルソナ

### メインペルソナ: アクティブせどり業者

- **年齢**: 20〜40代
- **職業**: 副業〜専業転売業者
- **行動パターン**: 週2〜3回リサイクルショップ・量販店を巡回、月売上10〜100万円
- **現在の課題**: Amazon・メルカリ両方を手動で検索するのが面倒。すぐ判断できないと商品を逃す
- **支払い意欲**: 月1,000〜2,000円は出す（Keepaも払っている）

### サブペルソナ: 初心者せどり業者

- **特徴**: せどり始めて3〜6ヶ月。無料ツールを使って月1〜10万円を目指している
- **ニーズ**: 何が儲かるかまずわかりたい
- **取り込み方**: 無料プランで体験 → 有料転換

---

## 機能要件

### コア機能（MVP必須）

#### F1: バーコード・QRコードスキャン
- カメラを起動してバーコードにかざすと自動認識
- JAN/EAN/UPC/QRコード対応
- 認識後0.5秒以内に検索開始

#### F2: 写真撮影 → AI商品認識
- 商品・パッケージの写真を撮影
- Google Vision APIで商品名・テキストを抽出
- 抽出されたキーワードで各サイトを検索
- バーコードがない商品（古着・骨董等）に対応

#### F3: テキスト検索
- 商品名を手入力して検索
- オートコンプリート機能

#### F4: 価格一覧表示
検索結果として以下を並べて表示:
- Amazon（新品・中古・FBA・自社出荷を区別）
- 楽天市場（最安値）
- メルカリ（直近の成約価格・出品中の最安値）
- ヤフオク（落札相場）
- 各サイトへのディープリンク（アフィリエイトタグ付き）

#### F5: 利益計算機能
- 「仕入れ値」を入力すると即座に計算:
  - 各サイトでの利益額
  - 利益率（%）
  - Amazon FBA手数料を差し引いた純利益
- 「儲かる / 微妙 / 損」を色で直感表示（緑 / 黄 / 赤）

#### F6: スキャン履歴
- 過去のスキャン結果を一覧表示
- 再検索ワンタップ
- 最大100件（無料）/ 無制限（有料）

---

### 有料プランのみ

#### F7: 価格アラート（Proプランのみ）
- 特定商品を「ウォッチリスト」に追加
- 設定価格を下回ったらプッシュ通知

#### F8: CSV出力（Proプランのみ）
- スキャン履歴を日付・利益率でソートしてCSV出力
- 確定申告・在庫管理に活用

#### F9: 価格履歴グラフ（Proプランのみ）
- Amazon価格の過去3ヶ月推移グラフ
- 「今が安いのか高いのか」を視覚化

## 非機能要件

| 要件 | 基準 |
|------|------|
| バーコード認識速度 | 1秒以内 |
| 価格取得速度（全サイト） | 3秒以内 |
| オフライン対応 | スキャン履歴のみ閲覧可能 |
| 対応OS | iOS 15以上 / Android 10以上 |
| 対応言語 | 日本語のみ（初期） |

---

## ユーザーフロー

### メインフロー: バーコードスキャン

```
アプリ起動
  └→ ホーム画面（カメラアイコン）
       └→ カメラ起動
            └→ バーコード検出（自動）
                 └→ 価格一覧表示
                      ├→ 仕入れ値入力 → 利益計算表示
                      ├→ 各サイトへの遷移（アフィリエイトリンク）
                      └→ ウォッチリストに追加
```

### サブフロー: 写真撮影

```
カメラ起動
  └→ 「写真で探す」タブ選択
       └→ 撮影 or ライブラリから選択
            └→ AI解析中（ローディング）
                 └→ 認識された商品候補を表示
                      └→ ユーザーが正しい商品を選択
                           └→ 価格一覧表示
```

---

## スコープ外（やらないこと）

- **在庫管理機能**: 別ツール（管理画面）で対応
- **仕入れ自動化**: 法的・倫理的リスクがある
- **海外Amazon対応**: 日本市場に集中（v1では）
- **ソーシャル機能（SNS連携）**: コアバリューに無関係
