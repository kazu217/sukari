プライバシーポリシー

制定日: 2026年7月21日

スキャリ（以下「本アプリ」）は、バーコードまたはテキスト検索により商品価格の比較を補助するアプリです。本ポリシーでは、本アプリにおける情報の取り扱いについて説明します。

取得する情報

本アプリは、バーコード読み取りのためにカメラを使用します。撮影映像は端末上でバーコード認識に利用され、当社が画像や映像を保存することはありません。

価格検索のため、入力または読み取られたバーコード・検索キーワードを、楽天市場、Yahoo!ショッピングなどの商品検索先に送信する場合があります。

利用目的

  • 商品価格の検索、比較、表示
  • 検索履歴や利益計算結果の表示
  • アプリの不具合調査および改善

第三者提供

法令に基づく場合を除き、取得した情報を本人の同意なく第三者へ販売または提供することはありません。ただし、商品検索の実行に必要な範囲で、検索キーワード等が外部サービスへ送信される場合があります。

外部サービス

本アプリでは、商品価格の取得やアプリ運営のために外部サービスを利用する場合があります。各サービスで取り扱われる情報は、それぞれのサービス提供者の規約およびプライバシーポリシーに従って管理されます。

免責事項

本アプリに表示される価格、在庫、商品情報、利益計算結果は参考情報です。実際の購入、販売、取引条件は各サービスまたは店舗で必ずご確認ください。

変更

本ポリシーは、必要に応じて変更される場合があります。重要な変更がある場合は、本ページ上でお知らせします。
