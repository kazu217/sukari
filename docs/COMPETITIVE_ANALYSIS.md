# 競合分析 — PriceLens（仮）

## ポジショニング

```
                    高い課金意欲（転売業者）
                           ↑
                           |
             [PriceLens]   |
  リアル      ─────────────┼─────────────  オンライン
  店舗特化                 |               特化
                           |   [PLUG]
                           |
                    低い課金意欲（一般消費者）
```

PriceLensは「リアル店舗 × 転売業者」という未開拓ポジション。

---

## 競合詳細

### 1. PLUG（株式会社STRACT）★最大の間接競合

**概要:** ショッピングアシストアプリ。ECサイト閲覧中に自動で最安値・キャッシュバックを表示。

| 項目 | 詳細 |
|------|------|
| ターゲット | 一般消費者（節約目的） |
| 使用場面 | オンラインショッピング中 |
| DL数 | 250万超 |
| 資金調達 | 累計14.1億円 |
| 年間GMV | 100億円超 |
| 収益源 | EC事業者からの成果報酬（BtoB2C） |
| 価格 | 無料（ユーザーへのキャッシュバックが売り） |

**PLUGの弱点（PriceLensの機会）:**
- リアル店舗では使えない
- 転売業者向け機能（利益計算、フリマ価格）がない
- バーコードスキャン機能なし
- モバイルアプリはサブ（メインはブラウザ拡張）

---

### 2. Amazon ショッピングアプリ

| 項目 | 詳細 |
|------|------|
| ターゲット | Amazon購入者 |
| バーコードスキャン | ✅ あり |
| 他サイト価格比較 | ✗ なし（Amazon内のみ） |
| フリマ価格 | ✗ なし |
| 利益計算 | ✗ なし |

**弱点:** Amazon以外の価格が見えない。転売業者には不完全。

---

### 3. Keepa

| 項目 | 詳細 |
|------|------|
| ターゲット | Amazon転売業者 |
| 主機能 | Amazon価格履歴・ランキング推移 |
| 料金 | 無料〜€19/月（約3,000円） |
| 対応プラットフォーム | PC（Chrome拡張）・モバイル |
| フリマ価格 | ✗ なし |
| 楽天価格 | ✗ なし |
| バーコードスキャン | ✗ なし（モバイルでも不便） |

**弱点:** 価格「履歴」はわかるが「今すぐ仕入れ判断」に使いにくい。リアル店舗での使用を想定していない。

---

### 4. SELMA（セルマ）

| 項目 | 詳細 |
|------|------|
| ターゲット | Amazonせどり業者 |
| 主機能 | バーコードスキャン + Amazon価格 + FBA手数料計算 |
| 料金 | 月額あり |
| フリマ価格 | △（一部対応） |
| 楽天価格 | ✗ |
| AI画像認識 | ✗ |

**弱点:** 楽天・フリマ対応が弱い。AI画像認識なし。UIが古い。

---

### 5. モノレート（サービス終了）

かつてAmazonの価格・ランキング推移を無料で見られたサービス。2019年に終了。
これにより**「手軽に使える無料の転売リサーチツール」は市場から消えた**。
この空白がPriceLensの大きな機会。

---

### 6. メルカリ・ヤフオクアプリ（出品側）

バーコードスキャンで出品情報を自動入力する機能はあるが、「仕入れ判断」には使えない。

## 参入障壁と差別化の持続性

### 短期的差別化（6ヶ月以内）
- AI画像認識の実装（競合は未対応）
- メルカリ・楽天・ヤフオクの4サイト同時比較

### 中期的参入障壁（6〜18ヶ月）
- ユーザーの利益履歴・スキャン履歴データ蓄積
- 「このジャンルの利益率が高い」学習機能
- せどり業者コミュニティのネットワーク効果

### 注意点
PLUGが「転売業者向け機能」を追加し始めたら直接競合になる。先行してユーザーを囲い込む速度が重要。
